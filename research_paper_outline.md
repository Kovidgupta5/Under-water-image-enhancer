## Abstract
Briefly summarize the entire paper in 150-250 words.
* **Problem:** Underwater photography suffers from severe color distortion, low contrast, and blurriness due to light absorption and scattering in water.
* **Solution:** We propose a dual-stage AI framework. First, a MobileNetV2-based classifier validates the scene to ensure it is an underwater environment. Second, a custom Convolutional Neural Network (CNN) architecture (inspired by WaterNet) intelligently blends the raw image with color-corrected (White Balanced) and contrast-enhanced (Histogram Equalized) versions of the image.
* **Implementation:** The system is deployed via a high-performance FastAPI backend and a modern React-based user interface.
* **Results:** The proposed method successfully restores lost red spectrums, removes blue/green color casts, and improves overall visibility without introducing artificial noise.

## 1. Introduction
* **Background:** The physics of underwater light (water absorbs red light first, leading to blue/green images; suspended particles cause scattering/fuzziness).
* **Motivation:** The need for clear underwater vision in marine biology research, underwater robotics (ROVs), and recreational photography.
* **Challenges:** Standard image enhancement tools fail because underwater degradation is depth-dependent and non-linear.
* **Contributions:** 
  1. A pre-processing classification step to reject non-underwater images.
  2. A neural blending model that combines the strengths of traditional physics-based enhancements with deep learning.
  3. A fully functional, open-source web application for end-users.

### 3.2 Pre-processing Inputs
Before entering the main enhancement model, the raw image is duplicated and processed two ways:
1. **White Balancing (WB):** Applied using the Gray-World assumption in the LAB color space to neutralize the dominant blue/green color cast.
2. **Histogram Equalization (HE):** Using CLAHE to improve local contrast and highlight hidden textures in shadows.

### 3.3 Neural Blending Architecture (WaterNet)
* Explain the neural network architecture used in `app.py`.
* The network takes a 9-channel input (Raw RGB + WB RGB + HE RGB).
* It uses sequential Convolutional layers (with PReLU activations) to extract features.
* The `confidence_head` outputs weight maps using a Softmax layer.
* The final image is generated by multiplying the inputs by these learned weights and summing them up.

### 3.4 Smart Post-Processing
* **Smart Red Clamp:** Ensures the red channel doesn't become over-saturated compared to the green channel.
* **Shadow Lift:** Applies a gentle gamma correction (`restored_t ** 0.85`) to brighten the dark areas common in deep-water photos.
